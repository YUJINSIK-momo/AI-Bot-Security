# NestJS

## 공개 경로 찾기(감사할 때)

- `@Controller()` + `@Get/@Post/...`, 전역 prefix(`app.setGlobalPrefix`).
- 가드: 전역(`APP_GUARD`)과 메서드 · 컨트롤러의 `@UseGuards`. 「공개」 표시(`@Public()` 같은 것)가 전역 가드를 비켜 가는지 본다.
- 경로마다 적는다: 인증 · 상한 · 비싼 호출(LLM SDK · 유료 외부 API · 무거운 쿼리) · 일괄 조회(`batch`) · 열거 가능한 인자(코드 · 순번 ID).

## 속도 제한

**@nestjs/throttler**(간단할 때)
- `ThrottlerModule.forRoot([{ ttl: 60_000, limit: 100 }])` + `APP_GUARD` 로 `ThrottlerGuard`. 경로별 `@Throttle({ default: { limit, ttl } })`, 빼기 `@SkipThrottle()`.
- 프록시 뒤면 Express 에 `app.set('trust proxy', 홉 수)` 를 주거나, 가드의 `getTracker` 를 바꿔 신뢰하는 IP 를 쓴다. `X-Forwarded-For` 첫 값을 그대로 쓰지 않는다.
- 기본 저장소는 메모리다. 서버가 여러 대면 Redis 저장소를 쓴다.

**직접 만든 가드**(경로 묶음 · 가중치가 필요할 때)
- 묶음별(예: 지도 · 리포트 · LLM) 고정 창 카운터. 열쇠 수 상한(오래 안 쓴 것부터 잊기)으로 메모리를 묶는다.
- 일괄 조회는 항목 수만큼 센다.
- 서버 내부 클라이언트(PDF 렌더러 등)는 서버만 아는 통행증 머리로 빼 준다. 통행증이 틀리면 실패시키지 말고 보통처럼 센다.
- 처음엔 「세기만」 모드(넘으면 로그만)로 내고, 값을 본 뒤 막기로 바꾼다.
- 로그에 IP 원문을 남기지 않는다(필요하면 프로세스마다 바뀌는 소금을 친 해시 앞부분).

## LLM 을 부르는 공개 경로

- 캐시에 없어 **새로 만들 때만** IP 상한 · 전체 상한을 쓴다. 막히면 화면이 감출 수 있는 빈 값(`null`)을 돌려준다.
- IP 상한을 먼저 보고, 거기서 막힌 시도는 전체 몫을 쓰지 않게 한다(전체 상한이 공격으로 바닥나지 않게).
- 캐시 크기가 작으면 훑기가 캐시를 밀어낸다 — 캐시 상한 · 저장 위치를 함께 본다.
