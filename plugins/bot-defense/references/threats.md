# 위협 모델 — AI 봇 · 크롤러 · 분석 에이전트

먼저 말해 둘 것: 브라우저로 내려간 것(화면 · JS · API 응답)은 누구든 가져갈 수 있다. 목표는 「완전 차단」이 아니라 넷이다.

1. 대량 복제를 느리고 비싸게 만든다.
2. 비용이 새는 길(공개 경로가 부르는 LLM · 유료 API)을 막는다.
3. 일어나는 것을 본다(탐지).
4. 문제 삼을 근거를 남긴다.

## 위협 여섯 가지

| # | 위협 | 어떻게 오나 | 스스로 이름을 밝히나 |
|---|---|---|---|
| T1 | 학습 · 검색용 AI 크롤러 | GPTBot · ClaudeBot · CCBot 등이 페이지를 수집 | 대부분 밝힌다(`data/ai-user-agents.tsv`) |
| T2 | 사용자 요청형 AI 읽기 | ChatGPT-User · Claude-User 처럼 사람이 시킨 페이지 읽기 | 밝힌다 |
| T3 | AI 에이전트 브라우저 | 실제 브라우저(헤드리스 포함)를 AI 가 조종해 화면을 돌며 수집 | 안 밝힌다 — 사람처럼 보인다 |
| T4 | 분석 에이전트(REA 류) | 사람이 자기 Chrome 으로 몇 분 써 본 기록(CDP · HAR)을 분석해 API 목록 · 응답 모양 · 화면 구조를 뽑고, 「다시 부를 수 있는 도구 목록」으로 만든다 | 안 밝힌다 — 관찰 단계는 평범한 사용 |
| T5 | API 대량 재호출 | T4 에서 얻은 API 를 스크립트로 전부 훑는다. 여러 IP · 주거용 프록시로 나눠 보내기도 한다 | 안 밝힌다 |
| T6 | 비용 고갈 | 로그인 없는 경로가 LLM · 유료 API 를 부르면, 훑기만으로 돈이 나가고 전체 상한이 차서 실제 사용자가 막힌다 | 안 밝힌다 |

T4 메모(REA, 2026-10 확인): 웹 대상은 「사용자 소유 Chrome 에 CDP 로 붙어 관찰」 · 「JS 번들 정적 분석(경로 · API 후보, 소스맵이 열려 있으면 원본)」 · 「HAR 분석 → environment manifest(다시 부를 수 있는 API 도구 목록)」 · 「Playwright 시나리오(기본 헤드리스)」다. 관찰 자체는 막을 수 없고, 막을 곳은 그다음의 T5 다.

## 자주 놓치는 것

- **화면에서만 막기:** 로그인 문구를 화면에 띄워도 API 가 공개면 T5 는 그대로다. 서버(가드 · 미들웨어)에서 막는지 본다.
- **프록시 뒤 IP:** `X-Forwarded-For` 의 첫 값은 위조할 수 있다. 신뢰하는 프록시가 붙인 값(보통 끝 값)이나 `trust proxy` 설정을 쓴다.
- **메모리 상한:** 앱 안에서 세면 서버 대수만큼 나뉘고 재시작하면 비워진다. 정확히 세려면 앞단(WAF)이나 공유 저장소(Redis 등)에서 센다.
- **전체 상한이 가용성 구멍:** LLM 전체 하루 상한은 비용은 지키지만, 공격자가 다 쓰면 실제 사용자가 막힌다. IP 상한을 먼저 보고, 막힌 시도는 전체 몫을 쓰지 않게 한다.
- **내부 클라이언트:** 서버 렌더러 · PDF 를 만드는 헤드리스 브라우저가 공개 경로를 부르면 한 IP 로 몰린다. IP 상한이 그걸 막지 않게 서버 전용 통행증으로 빼 준다.
- **소스맵 · 키:** 운영에 소스맵이 열려 있으면 원본 코드가 보인다. 번들에 실리는 지도 · 분석 키는 도메인(리퍼러) 제한을 건다. secret 형식 키가 번들에 있으면 즉시 교체한다.
- **캐시 상한:** LLM 결과 캐시가 작으면, 훑기가 캐시를 밀어내서 실제 사용자 요청도 다시 LLM 을 부른다.
- **캐시 오염:** 요청의 자유 글(라벨 · 이름)이 프롬프트에 들어가는데 캐시 열쇠에 빠져 있으면, 처음 부른 사람의 글로 만든 결과가 모두에게 나간다. 표시용 값은 서버가 코드로 찾아 넣고, 받은 글은 쓰지 않거나 길이를 묶는다.
- **내부 중계의 IP:** 서버가 요청을 127.0.0.1 로 중계하면서 원래 IP 를 넘기지 않으면, 모든 사용자가 IP 하나의 몫을 나눠 쓴다.
- **보이지 않음:** 요청 로그 · 접근 로그가 없으면 훑기를 보지도, 나중에 증명하지도 못한다. 개인정보처리방침이 적은 보관(예: 접속 IP 1년)과 실제가 다르면 그 자체가 법무 확인 항목이다.
- **개발용 주소가 등록된 운영 키:** 지도 · 분석 키에 localhost 가 운영 도메인과 함께 등록되어 있으면, 누구나 자기 PC 에서 운영 키를 쓴다. 개발용 키를 따로 둔다.

## 하지 않는 것

- **JS 난독화 · 개발자 도구 감지 · 우클릭 막기:** 분석 도구는 압축 · 난독화된 코드도 그대로 분석한다. 실제 사용자만 불편해진다.
- **봇 이름만 믿기:** User-Agent 는 아무나 쓴다. 이름 규칙은 T1 · T2 용이고, T3 ~ T5 는 속도 · 로그인 · 브라우저 확인이 맡는다.
- **남의 사이트 탐색:** 이 플러그인은 내 서비스(또는 점검 권한이 있는 서비스)에만 쓴다.

## 법(나라마다 다르다 — 법무 확인)

- 약관의 금지 조항, 로그인 때 남는 동의 기록, 기술적 보호조치(로그인 · 속도 제한)가 있었는지가 나중에 다툴 때 근거가 된다.
- 한국은 부정경쟁방지법의 데이터 부정사용 조항과 저작권법의 데이터베이스 제작자 권리가 거론된다. 데이터 조항은 「특정인 또는 특정 다수에게 제공되는」 데이터를 말해서, 누구에게나 공개한 데이터는 보호가 약하다는 해석이 있다. 판단은 법무가 한다.
- 원천이 공공데이터인 숫자는 그 자체로 독점을 주장하기 어렵다. 지킬 가치가 큰 것은 가공 결과 · 해설 · 계산 로직 · 화면 경험이다.
